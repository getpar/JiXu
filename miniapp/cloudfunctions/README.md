## 二、原理 30 秒说明（了解即可，可跳过）

微信的规矩：**普通小程序不能随便给用户发通知**，必须用户先「点头同意」，每同意一次，你才能给他发 **1 条**。

- 用户在「待办事项」页点一下 **🔔 开启到期提醒** → 微信弹窗问「是否接收到期提醒」→ 用户点「允许」→ 你获得 **1 次**发送额度。
- 用户如果勾选了弹窗里的 **「总是保持以上选择，不再询问」**，之后他每次点这个按钮都**不再弹窗**、直接记一次额度 —— 所以用户点 5 次就攒了 5 次额度，5 天里每天都能收到一条。
- 每天 **早上 8:00**，云函数自动跑一趟：谁的待办今天到期、且还有额度，就给他发一条微信「服务通知」。

**这就是「一次性订阅 + 攒额度」方案。** 它不需要企业资质、不需要特殊类目，个人开发者也能用。

## 八、常见问题

| 现象 | 原因 / 解决 |
|------|------------|
| 点「开启到期提醒」提示 **「尚未配置订阅消息模板」** | 模板 ID 还没填，或填错了。检查 `push.ts` 的 `PUSH_TMPL_ID`。 |
| 提示 **「未连接云环境」** | 云同步没连上（云环境 ID 没配 / 控制台没关联小程序 AppID）。先修好云同步。 |
| 提示 **「订阅弹窗未打开，请重试」** | 多半不是从用户点击里触发的；正常点按钮不会出现。基础库过低也会这样。 |
| 云函数报 **`47003`** | 模板字段名对不上。把模板详情截图发我。 |
| 云函数报 **`43101`** | 用户拒收/已取消订阅 —— 属于正常，代码会自动把该用户额度清零。 |
| 云函数报 **`40003`** | openid 无效（用户删了小程序等），忽略即可。 |
| 一直收不到通知 | ①额度用完了（每天一条，点一次攒一次）；②`MINIPROGRAM_STATE` 没改成 `developer/trial`（测试期）；③手机没开「服务通知」免打扰。 |
| 上传云函数时弹出「创建云开发环境」并要 ¥19.9 | **别付钱**。点窗口**右上角「使用已有腾讯云环境」**，选 `daily-notes-d3gaotrwyc09ff44a`。详见第五步的避坑说明。 |
| 上传报 `请在编辑器云函数根目录（cloudfunctionRoot）选择一个云环境` | 右键 **`cloudfunctions` 根目录** → **「当前环境」/「切换环境」** → 选 `daily-notes`。详见第五步 3.1。 |
| 定时没触发 | 云开发控制台 → 云函数 → `dailyReminder` → 「触发器」标签，确认有个每天 08:00 的定时器。首次上传后可能要等几分钟生效。 |
