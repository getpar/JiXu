# account 云函数 — 部署说明（微信身份登录）

> 这个云函数只做一件事：**把微信身份（OPENID）换算成一个账本码（ownerId）**。
> 小程序启动时自动调用，用户不需要登录、不需要输入同步码。

---

## 一、你只需要做 3 步

### 第 1 步：用微信开发者工具打开项目

打开 `D:\CodexDemo\JiXu\miniapp\dist`（先跑过 `npm run build:weapp`，云函数会自动复制进 `dist/cloudfunctions/`）。

### 第 2 步：上传部署云函数

1. 左侧文件树找到 `cloudfunctions` 文件夹；
2. **右键 `cloudfunctions` →「当前环境」→ 选 `daily-notes`（体验版）**（不选会上传报错）；
3. 右键 `cloudfunctions/account` → **「创建并部署：云端安装依赖」**；
4. 等右下角提示「部署成功」。

> 不需要手动建 `accounts` 集合：云函数第一次运行会自动创建。

### 第 3 步：确认 `records` 集合权限

云开发控制台 → 数据库 → `records` → 权限设置：

**「所有用户可读，仅创建者可读写」**

（这是三端同步一直在用的权限，不要改成「仅创建者可读写」，否则小程序扫码读不到电脑端创建的配对请求。）

---

## 二、怎么验证成功

1. 重新进入小程序（或下拉刷新）；
2. 首页 → 云同步；
3. 顶部显示 **「微信身份：已自动登录（无需同步码）」** = 成功；
4. 如果显示「未绑定/不可用」，点一下那行会重试，并显示具体原因。

常见失败原因：

| 提示 | 原因 | 解决 |
|------|------|------|
| `account 云函数可能还没部署` | 云函数没上传 | 按上面第 2 步重新部署 |
| `请在编辑器云函数根目录选择一个云环境` | 没选环境 | 右键 `cloudfunctions` 选 `daily-notes` |
| `未连接云环境` | 小程序没关联 CloudBase 环境 | 云开发控制台 → 环境设置 → 小程序认证 → 扫码授权 |
| `这个账本已绑定其他微信` | 本机旧同步码已被另一个微信认领 | 在「高级（备用同步码）」里换一个码，或换回原微信 |

## 三、安卓「小程序码」配对（v1.2.1）

安卓端主推流程：安卓 App 生成一张**微信小程序码** → 保存到相册 → 微信「扫一扫」→ 从相册选择 → 小程序自动确认。

云函数 `account` 新增了 `createMiniCode` 动作，`config.json` 已声明 `wxacode.getUnlimited` 权限；重新部署 `account` 后即可使用。

注意：

- 小程序必须**已发布正式版/体验版**（`wxacode.getUnlimited` 才能生成码）；当前版本新增了 `pages/pair/index` 页面，需要先重新上传一版小程序。
- 如果安卓调用时报 `EXCEED_AUTHORITY` / `PERMISSION_DENIED`：云开发控制台 → 云函数 → 权限控制，给 `account` 配置 `"invoke": true`（允许客户端调用），或按 CloudBase OPA 策略放行匿名调用。
- 如果生成失败，安卓端会自动提示「请用 6 位配对码」——6 位备用流程不需要这个权限。

---

## 四、自定义云环境

如果你在云同步弹窗「自定义云环境 ID（高级）」里填了自己的 CloudBase 环境：

- 需要把 `account` 云函数也部署到**那个环境**；
- 那个环境里的 `records` 集合同样设为「所有用户可读，仅创建者可读写」；
- 否则小程序会退回本机同步码模式，但不会影响本地记账。

---

## 五、安全说明

- `accounts` 集合只存 `openid → ownerId` 映射，客户端从不直接读，只有云函数（管理员权限）访问；
- 小程序端拿到的永远只是账本码 `ownerId`，拿不到你的 openid；
- 本方案解决“不用同步码 + 换手机找回”，不等于“绝对防盗”；真正只有本人可读需要后续把读取也收到云函数后面（见技术方案第 6 节）。
