## 三、发现的问题（需要处理）

### 1. 安卓「生成安卓配对二维码」失败

实测点击后提示：

```text
生成小程序码失败：云函数 account 调用失败：HTTP 403
{"code":"EXCEED_AUTHORITY","message":"Request exceeds granted authority..."}
```

**原因**：Android 通过 CloudBase HTTP API 以匿名身份调用 `account` 云函数，当前云函数权限规则不允许匿名调用。

**影响**：安卓新版「小程序码扫码绑定」无法生成二维码；6 位备用码入口仍可用（依赖小程序生成手机绑定码）。

**处理方式**：在 CloudBase 控制台 → 云函数 → 权限控制，把 `account` 的 `invoke` 设为允许（或配置 OPA 策略允许该匿名调用）。详见 `miniapp/cloudfunctions/account/README.md`。

### 2. 小程序新版配对页尚未上传

`miniapp/dist` 已包含新页面 `pages/pair/index`，但真机要使用安卓小程序码，需要先把新版小程序上传/发布，否则微信扫到的小程序码打不开配对页。
