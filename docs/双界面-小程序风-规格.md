# 双界面规格：夜航仪表 · 小程序靛风

> 目标：Android App 与 Windows 桌面端都提供「界面风格」选择。
> 两套风格共用同一份业务逻辑、数据与云同步；只切换视觉层与布局皮肤。

## 1. 两套风格

| | 夜航仪表（instrument，保留现状） | 小程序靛风（miniapp，新增） |
|---|---|---|
| 气质 | 精密仪表盘、暗色科技感 | 清爽白卡、现代移动端 |
| 底色 | 深色 `#0A0B0D` / 浅色 `#E6E7E2` | 浅色 `#F5F6F8` / 深色 `#0E0F13` |
| 卡片 | 直角 2dp、1dp 发丝边、四角 L 形角标 | 圆角 16dp、白卡、无描边无阴影 |
| 主色 | 荧光绿 `#D4FF3F`（深色）/ 深橄榄 `#4B6400`（浅色） | 深靛蓝 `#2E3A8C`（浅色）/ `#7C89E0`（深色） |
| 数字 | Martian Mono 等宽、细字重、大号读数 | 系统无衬线、中等字重、tabular-nums |
| 微标签 | 大写英文、等宽、字距 .12em | 不显示英文微标签；中文小字灰色 |
| 底栏 | 中间凸起圆形「+」 | 四项等宽普通页签，无凸起 |

## 3. 组件映射

| 组件 | 夜航仪表 | 小程序靛风 |
|---|---|---|
| 面板 | `Panel`：直角 + 角标 + 1dp 边 | 圆角 16dp 白卡，无角标无边框 |
| 模块标题 | 编号 + 中文 + 英文微标签 | 仅中文标题，15sp / 500 |
| 按钮（主） | 直角荧光绿底 | 圆角 10dp 深靛蓝底白字 |
| 分段 / 筹码 | 直角、反白选中 | 圆角 8–10dp、浅底选中 |
| 输入框 | 下划线极简 | 浅灰圆角底 `#F1F2F5`，10dp |
| 弹窗 | 直角、1dp 边 | 圆角 20dp 白卡 |
| 金额数字 | 等宽细体、超大号 | 系统无衬线、500 字重、tabular-nums |
| 首页主卡 | 「本月支出」大数字 | 「本月结余」深靛蓝主卡：结余 + 支出/收入 |
| 首页快捷入口 | 6 个方角按钮网格 | 白卡内三列细线网格（6 项） |
| 最近记录 | 仪表行 | 白卡列表行：分类 + 日期/备注 + 金额 |
| 底栏 | 选中顶部 2dp 短条 + 凸起「+」 | 四项普通页签，选中主色 |

## 4. 交互与数据约束

- 风格偏好独立于明暗偏好：`ui_style = instrument | miniapp`；两套风格都支持浅色/深色。
- 切换立即生效并持久化；不重建业务状态、不触发同步、不改任何数据。
- 金额精度、日期时区、云同步字段、去重键与现有实现完全一致。
- 桌面端保留左侧导航和桌面信息密度；只把视觉语言切到小程序靛风，不把桌面强行做成手机窄屏。
- Android 端保留系统返回、手势和小程序端已有交互习惯；不改变通知/闹钟逻辑。
